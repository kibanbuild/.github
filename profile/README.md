# 基盤 · Kiban

**Platform tools, built foundation-first.**

</div>

---

Kiban builds tools for the platform layer: the infrastructure other software runs on.
Exporters, infrastructure checks, and the small pieces that keep cloud systems in order.

基盤 (*kiban*) means foundation. It's the part you don't see and can't skip, and the
part that matters most when something breaks.

## Around here

- Each tool is small, does one job well, and says clearly what it doesn't do.
